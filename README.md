# True Adaptive Music

Attribution:

True Adaptive Music (TAM) release builds contain custom release binaries of FFmpeg, which are licensed under the same GPLv3 that TAM builds are protected by.
While TAM is not a derivative work of FFmpeg due to sole interaction with these binaries via IPC, TAM nevertheless remains compliant with the same licensing protecting said FFmpeg binaries.

![True adaptive music logo](src/main/resources/assets/trueadaptivemusic/icon.png)

True Adaptive Music is a fabric mod that enables adding custom adaptive music by creating Music Packs, and supports injection into numerous in-game events.

Read the Wiki [here](https://liltojustice.github.io/TrueAdaptiveMusic/)!
