# True Adaptive Music v2.6.0

## New Features:
### Node Option: Disable Fading
- When entering a node with this option enabled, no fading will occur.

## Predicate Types:
### On Fluid
- Triggers whenever the player is *on* a fluid, converse from the "In Fluid" predicate.
- Can also work with vehicles riding on water (i.e. boats).

## Fixes:
- Compatible audio file types are now listed when selecting music
- Fix an issue where music would not play for a while if on linux operating systems on earlier minecraft versions
