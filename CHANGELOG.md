True Adaptive Music v1.7.1

Minor Fixes/Changes:
- The widget to create a new child node now only shows for the node that is selected (and the root node)
- A bunch of UI bug fixes including events not saving
- Zip files now use the standard file separator (old packs still won't work on linux/mac unless they are re-exported)
- Some older packs would not load properly due to missing properties from newer packs, fixed

Known Issue:
- Events with state (Combat, InWater/Lava, EntityNearby) don't work properly because of a serialization issue, will be fixed tomorrow in 1.7.2
